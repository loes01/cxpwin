# cxp for windows

COMMANDS ( TAB MODE )
=========================
* find.(input)
    + finds the files that starts with the input
* go (input)
    + goes to a directory that user has put in.
* quit
    + quits.
* view.(filename.extension)
    + opens the file and shows it to the user.
